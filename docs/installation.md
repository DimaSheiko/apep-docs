# Installation Guide

Follow these steps to successfully install and configure Apep.

## Step 1: Download Apep

1. Join our Discord server by clicking this [link](https://discord.gg/ZXrZZbTqZ9).
2. Download the Apep installation file from the server.
3. Extract the downloaded archive to a location of your choice on your computer.

## Step 2: Install Apep

1. Navigate to the directory where you extracted the archive.
2. Run `Apep.exe` to start the installation process.

!!! warning "Compatibility Notice"

     Apep is only compatible with 32-bit clients on versions older than 9.2.7. If you are using a 64-bit client on these older versions, you must downgrade to a 32-bit version.

## Step 3: Configure Apep

Before using Apep, you need to configure it correctly:

1. Specify the location of your WoW client:

    - Open `Apep.exe`.
    - Click on the input field and select your `wow.exe` file.

2. After the initial run of `Apep.exe`, a configuration file named `settings{version}.json` will be created in the same directory as `Apep.exe`.
    - You don't need to edit this file, but you can view it with a text editor if desired.

By following these steps, you should have Apep installed and ready to use.
